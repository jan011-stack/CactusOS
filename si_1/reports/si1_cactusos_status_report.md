## 1. Current State Summary

CactusOS (upstream Remco123) is a 32-bit hobby operating system written primarily in C++ with some C and Assembly. It features:

- Higher-half kernel
- Basic PCI enumeration
- VESA graphics after boot
- ATA/ATAPI + basic AHCI
- ISO9660 + basic FAT12/16/32
- Multitasking (basic)
- Usermode support
- Graphical desktop + compositor
- USB (UHCI/OHCI/EHCI) + mouse/keyboard/mass storage
- Simple apps: Calculator, Clock, Terminal, Minesweeper
- Installer + boot-from-USB

**Strengths**
- Complete enough to boot and run a graphical desktop
- Clean separation of kernel / apps / initrd
- Educational value for OSDev

**Critical gaps (2026 perspective)**
- No 64-bit / long mode support
- No SMP / multi-core
- No modern interrupt controller (APIC/IOAPIC) path fully utilized
- xHCI missing
- Filesystem stack is fragile (especially FAT write path)
- Build system relies on outdated i686-elf toolchain assumptions
- No continuous integration
- Documentation is sparse and outdated
- No formal contribution / security policy
- Compositor and GUI look dated and lack accessibility/modern input handling
